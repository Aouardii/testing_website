# Aloe Matcha

Landing page de préouverture pour Aloe Matcha à Rambouillet.

## Lancer le site localement

Depuis PowerShell, dans ce dossier :

```powershell
python -m http.server 8765
```

Puis ouvrir <http://localhost:8765>.

Le site est statique et ne nécessite aucune installation. Pour le publier, les fichiers peuvent
être déposés tels quels sur GitHub Pages, Netlify ou Cloudflare Pages.

## Ajouter Instagram

Lorsque le compte existe, remplacer les boutons portant l'attribut
`data-instagram-placeholder` dans `index.html` par des liens vers le profil Instagram.
